# 타닥 가계부

계산기로 타닥타닥 입력하면 투명 바인더 포켓에서 돈이 빠져나가는 가계부예요.

- 로그인 없이 브라우저로 열어서 바로 써요.
- 기록은 **이 기기의 브라우저에만** 저장돼요. 서버로 보내지 않아요.
- 엔(¥)과 원(₩)을 고를 수 있고, 월급날부터 다음 달 전날까지를 한 달로 봐요.
- 홈 화면에 추가하면 앱처럼 쓸 수 있고, 오프라인에서도 열려요.

## 기록 지키기

기록은 브라우저 저장소에 있어서, 브라우저 데이터를 지우거나 기기를 바꾸면 사라져요.

- **설정 → 백업 → 백업 파일 저장**으로 가끔 파일을 저장해 두세요. 다른 기기에서는 **백업 파일 불러오기**로 이어 쓸 수 있어요.
- PC의 Chrome·Edge에서는 **자동 백업 파일 고르기**로 파일 하나를 정해 두면, 기록할 때마다 그 파일에 저장돼요.
- 아이폰은 Safari에서 **공유 → 홈 화면에 추가**를 해야 기록이 더 오래 안전하게 보관돼요.

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만들어요. (예: `tadak-gagebu`, Public)
2. 이 `public` 폴더 **안의 파일들**을 저장소 맨 위에 올려요.
   `index.html`, `manifest.webmanifest`, `sw.js`, `README.md`, `icons/` 폴더
   (웹에서 **Add file → Upload files**로 끌어다 놓으면 돼요)
3. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 저장해요.
4. 1~2분 뒤 `https://<내 아이디>.github.io/tadak-gagebu/` 주소로 열려요. 이 주소를 공유하면 돼요.

앱을 고친 뒤 다시 올릴 때는 `sw.js`의 `CACHE` 이름 끝 숫자를 올려 주세요(예: `v1` → `v2`). 그래야 이미 설치한 사람도 새 버전을 받아요.
